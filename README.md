# PF: minijogos

Feito em mai/2023 a jun/2023, na faculdade. Está aqui como arquivo: o código ficou do jeito que era na época.

PF do semestre: tela de login, escolha de animal e dois minijogos. Um é de avião (atira, desvia de objetos, tem cronômetro e game over) e o outro é o do dinossauro. O `Player.cs` e o `Laser.cs` vieram do SpaceShip Game, e o `AudioManager` de projetos anteriores.

## Como abrir

Na época só exportei a pasta Assets num `.unitypackage`, então não tem ProjectSettings. Crie um projeto 2D vazio no Unity (nessa época eu usava a 2021.3) e importe `pacote-original/PF_Dimas.unitypackage` em Assets > Import Package > Custom Package.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
